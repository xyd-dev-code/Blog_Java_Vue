# 武侠主副标题字体与题字

上次错误地把字体参考扩展为字号、行高、字距和换行规则调整，造成实际布局变化。这些排版覆盖已撤销，不能再将旧的归一化验证记录作为“布局未变”的依据。

## 当前范围（2026-08-31 用户追加要求）

- 用户先接受首页题字图片方案，随后明确要求“其他主标题和副标题也要改”，因此前台各页主副标题已纳入范围。内页文案随后恢复为“所有文章、我的项目、在线工具箱”等原名称；题字使用这些最新名称，不回滚文案修改。
- 首页“拾光小筑 / 仗剑天涯”保留已确认的两行题字，图片文件及原有尺寸不变。
- 内页固定主标题、首页三个分区标题使用同风格题字图集；长副标题、分区说明、CTA 标题说明、文章详情标题摘要、分类名及标签名采用本地庞门正道粗书体。
- 字体只应用于明确列举的前台标题与说明选择器；文章正文中的 h1/h2/h3、卡片正文、导航、控件、后台和晴天主题不应用该字体。
- 保留原有字号、字重、行高、字距、换行、对齐和间距规则。题字由真实文字占位，图片叠在相同文字框内；图片不可用时直接显示文字。
- 不更改按钮、天气卡、导航、背景及正文容器的布局规则；不添加标题卡片或额外留白。
