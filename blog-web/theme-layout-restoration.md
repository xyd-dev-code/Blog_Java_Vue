# 主题布局恢复验证

字体改动纠正：参考字体不授权调整布局。已撤销标题字号、行高、字距和换行覆盖，只保留首页首屏字体替换；其他区域恢复原样。当前约束见 `wuxia-typography.md`。

后续修正：已撤销为避让剑客而错误增加的文案边距，首页及内页均继续采用下文的原始布局基准。人物只在现有装饰留白内移动、缩放和裁切，不改变标题、说明、按钮、天气卡及下方区块的位置。当前验证记录见 `wuxia-theme-qa.md`。

基准：仓库 HEAD 中的原始晴天前台组件。主题仅替换已有表面的配色、纹理与背景装饰。

已恢复：

- 首页标题区不再通过伪元素包成卡片。
- 页眉恢复原有悬浮导航容器，不把容器背景扩展到整条页眉。
- 评论列表取消新增背景、边框、阴影和内边距，恢复原始评论排版。
- 圆角、头像形状、图标、字体加载和字体度量沿用原始设计。
- 清除额外页头边框；主题缓存版本更新为 3，避免旧形状 token 残留。

验证结果：

- `npm run test:theme-layout -- --baseline=HEAD`：通过，54 个原始组件/样式文件的布局声明一致。
- `npm run test:theme-layout:browser`：通过，12 个页面 × 3 个视口，36 组、8,363 个元素，0 个几何或组件形状差异，0 个运行时异常。
- 视口：1440 × 900、768 × 1024、390 × 844。
- 页面：首页、文章列表、文章详情、分类、标签、项目、工具、友链、留言、关于、归档、搜索。
- `npm run build`：通过。构建仍提示依赖内已有的 PURE 注释警告，不影响输出。
- `git diff --check`：通过。

浏览器测试使用固定数据，拦截 API 请求，不写入后端；本地后端未运行，因此不将本次测试表述为真实业务数据的端到端验证。字体网络请求同样固定为系统回退，字体加载配置另与原始源码比对。

主题约束检查不仅检查 `data-theme` 内部，也检查整份主题样式文件，防止把布局覆盖移到主题选择器外绕过约束。仅背景画作的层叠上下文和装饰动画允许定位规则。

详细 JSON 和两主题桌面/移动端截图位于 `design-qa-assets/theme-layout-regression/`。

## 首页顶部背景补齐

- 原因：纸纹仅绘制在正文和首屏内部，固定导航的顶部预留区露出全局渐变。
- 修复：仅在水墨首页将纸面背景统一绘制到现有 `.front-layout`，正文和首屏不再重复叠加纸底，导航顶部、左右两侧与正文连续衔接。
- 不变：没有改动 DOM、导航尺寸、顶部预留空间、内容间距或山水/树叶的定位规则；其他路由与晴天主题不受此规则影响。
- 浏览器回归新增 `backgroundPass`，检查背景覆盖顶端和两侧、纸纹加载成功、首屏不重新铺底、晴天不出现纸纹，以及背景素材矩形不变。
- 桌面、平板、手机截图均已人工核对顶部衔接；原有 36 组布局回归、源码布局约束和生产构建继续通过。
