# 历史：几何纹理内页方案

实现只涉及 `src/styles/themes.scss` 的背景声明与背景变量。首页完整保留，晴天主题不变；没有改动组件结构、业务逻辑、排版、字体、前景色、尺寸、间距、圆角或交互。新增纹理全部由 CSS 渐变绘制，没有新增依赖、图片或字体。原有内容封面和缺省封面保持不变。

## 共用画法与差异来源

宣纸底色继续使用 `--c-paper`（#f2f3f4），墨、青、朱、梅、蓝均取自现有主题 RGB 变量。统一使用「淡纹理 → 中央纸色罩染 → 下部归纸 → 入口墨晕 → 收尾墨晕 → 定向底色」六组背景；工具页的网格有两层纹理。页面通过纹理形态、方向、间距、墨晕位置及阅读留白共同区分，不只替换一种颜色。

入口墨晕源透明度 26%，收尾 12%；定向底色 10% → 0% → 4%。这些颜色位于纸色罩染下方，实际可见强度更低。页面节奏是背景的视觉引导，不新增分区，也不改变操作流程或滚动行为。

下表角度遵循 CSS：0° 向上、90° 向右、180° 向下。纹理尺寸为 CSS px。留白表示中央纸色罩染 alpha ≥ 0.88 的区域占画布面积的**近似比例**，按实际椭圆半径和画布裁切估算；不是 DOM 空白、容器宽度或删减内容的比例。该区仍保留很淡的纸纹。

## 层级、透明度、模糊和阴影

规则：**导航层 > 内容层 > 装饰覆盖层**。此处“覆盖层”专指背景罩染、墨晕和纹理，不能等同于模态弹窗遮罩；真实弹窗、移动菜单及其遮罩继续遵循现有交互层级。本次没有改动任何 `z-index` 声明，层级变量仅记录现有契约。

| 层 | 既有层级 / 新增说明变量 | 背景 alpha | 模糊 | 阴影 |
|---|---|---|---|---|
| 前台导航 | z=100；`--wuxia-layer-navigation:100` | 纸面 0.98；夜间 1；文字本身透明度不变 | 沿用 backdrop blur(14px) | 沿用 `--shadow-soft`：0 1px 2px / 8% 墨色，0 12px 34px / 7% 墨色 |
| 内容 | `.front-main` z=1；`--wuxia-layer-content:1` | 实纸卡片底色 1；中央背景纸色罩染 0.98 → 0.88；透明容器保留原规则 | 常规内容无新增模糊（0px）；已有特殊组件滤镜不动 | 文章卡沿用 0 12px 34px / 8%，悬停 0 18px 42px / 13%；其他卡沿用现有阴影变量 |
| 装饰覆盖 | 新增纹理直接绘在容器 background；旧墨景 z=-1；`--wuxia-layer-decoration:-1` | 细纹 0.018–0.028，专属纹 0.035–0.11；下层墨晕 0.26 / 0.12 | 新增 filter blur 为 0px；柔边由渐变产生 | 无新增阴影；不创建节点，不接收点击 |

背景图层自上而下叠加，纹理不混合文字，不修改整个内容容器的 `opacity`。后台的固定侧栏、移动侧栏及遮罩继续使用原组件层叠规则。

## 明暗模式、尺寸与高分屏

- 复用 `html[data-theme='ink']` 与现有 RGB token；只在 `data-wuxia-page` 标识存在的非首页启用。新规则不进入首页或晴天主题。
- `prefers-color-scheme: dark` 下画布改为 `--c-ink-950`，末端改为 `--c-ink-900`。由于现有两个主题都声明 `color-scheme: light`，且本次禁止改文字色，采用**深墨外侧画布 + 明亮阅读纸面**，不是完整反色深色 UI。中央纸面宽度上限 1280px；窄屏两侧仅留 6px 暗边，避免深字落到深底。表单原生控件继续沿用现有主题。
- ≤768px：默认细纹 alpha 从 0.028 降为 0.018，背景由 fixed 改为 scroll；专属稀疏纹理保留形态。没有改变容器尺寸、布局断点或 DOM 留白。
- DPR 1 / 2 / 3：默认细线分别为 1 / 0.5 / 0.333333 CSS px；间距不变。项目墨带、笺纸横线、点阵与弧线的设计粗细使用 CSS px，始终由浏览器矢量绘制，不会放大位图。
- 没有新增背景动画，沿用项目减弱动态规则；打印时改为无纹理白底。
