# 非首页武侠风格增强

## 页面标题原文恢复（最新修正）

按用户要求，前台各页主标题、副标题和顶部小标题固定使用原文，不参与武侠文案替换。范围包含文章、项目、工具、友链、留言、关于、归档、搜索、分类、标签和 404；文章数、搜索结果数以及分类/标签的用户自定义描述继续动态显示。导航原文保持前次恢复结果。

本次只撤销上述文字的 `wx` 调用，没有修改 CSS、字体资源、背景、布局和用户内容。保留题字组件原有的按文字精确匹配机制；恢复后的标题使用现有字体显示，不把旧的武侠题字图片冒充原文。首页及其他按钮、表单提示不在本次修改范围内。

验证使用现有浏览器核查脚本和固定 API 数据；快照位于 `design-qa-assets/original-heading-copy/`，生产构建通过。

## 页头构图恢复（最新修正）

此前给内页统一叠加山水横幅、底部分界线，并在项目页右侧重复铺图，改变了原有留白和装饰构图。即使容器几何检查通过，也不能据此声称页面视觉布局没有变化；用户截图中的问题来自这组跨页面背景覆盖。

- 已撤回统一页头背景图、分界阴影、原有装饰的额外透明度覆盖及项目页右侧重复背景。搜索控件也恢复由原组件管理表面样式。
- 保留当前字体、武侠文案、首页、导航、内容卡片和功能；没有修改 DOM、容器尺寸、字号、间距或对齐规则。
- 对比参考为最初保存的 `before-1440-*.png`；本次修复前后快照、截图及报告另存于 `design-qa-assets/header-restoration/`，不覆盖旧基线。
- 六个反馈页面 × 四个视口（1910、1440、768、390）× 两种主题，共 48 组、624 个容器：没有几何或排版差异、没有新增横向溢出及运行时异常。两种主题实际文案均未改变，晴天页头绘制样式未改变。
- `header-paint-report.json` 单独记录页头背景图与阴影检查，确认山水横幅和分界线已移除；六个页面的桌面及手机截图已逐页核对。验证使用固定 API 数据，不修改后端。

采用保留式增强：延续首页的灰白宣纸、墨黑与朱砂，沿用 Vue、Element Plus、已有山水画作与书法字体。布局、动效强度和信息密度沿用现状，不重新设计页面。

## 实现范围

- 前台文章列表与详情、分类、标签、项目、工具、友链、留言、关于、归档、搜索及 404。
- 登录页和所有后台页面，包括管理页中的分类、标签、举报等标签页。
- 页眉、手机菜单、页脚、弹窗、空状态和操作提示。
- `useWuxiaCopy` 只在 `ink` 主题且路由不是 `/` 时提供武侠文案。切换回晴天或返回首页会恢复原文案；文章、用户资料、分类名称等接口内容不经过词典替换。
- `themes.scss` 的新增规则由 `.app-root[data-wuxia-page]` 限定，包括挂载到 body 的弹窗。仅增加背景、纸纹、颜色、边缘阴影及按钮剑光；没有新增布局容器、字号、间距、边框宽度、圆角或定位规则。
- 沿用首页画作和纸纹，不添加运行时依赖。用户封面、头像、站点名称及后台配置不变；删除、审核、登录校验及订阅确认仍保持明确的语义。

## 原始基线与排版修复

此前“布局未变”的结论不成立。全局标题、副标题样式覆盖了非首页的字号、行高、字距和换行规则，造成排版变化；验证时又将已经变化的公共字体纳入新基线，漏掉了这个问题。

`design-qa-assets/wuxia-pages/final/report.json` 仅证明两份已采用新字体的快照之间没有容器差异，**不能证明原始布局得到保留，不再作为验收依据**。原始基线始终保留在 `design-qa-assets/wuxia-pages/before.json`，源码位置记录在同目录 `baseline-path.txt`。

本次修复恢复非首页原有的 Ma Shan Zheng 标题字体，移除非首页的全局排版指标覆盖，由原组件决定字号、行高、字距与换行。首页字体规则限制在 `.front-layout:has(.home-sky)` 内；非首页的水墨、宣纸、朱砂与武侠文案继续保留。

修复后的回归放在 `design-qa-assets/wuxia-pages/layout-restored/`，直接与最初保存的原始基线比较，保留真实文案，不重设字体基线。检查覆盖 28 个非首页路由状态、3 个视口和 2 套主题；具体结果以该目录的 `report.json` 为准。文章页测量等待入场过渡完成，避免记录临时缩放。

修复验证通过：168 组页面、1,818 个容器，没有超过 1px 容差的位置或尺寸差异，没有排版样式差异、新增横向溢出或运行时异常；晴天文案一致。构建通过，静态检查不再放行字号、行高、字距和换行规则。

现有 `test:theme-layout:browser` 将非首页两种主题的文本统一后比较皮肤几何，仍严格检查全部原有元素；实际文案的布局和换行由上述前后快照回归单独验证。

测试均使用本地固定 API 数据，不读取真实管理员会话，不保存表单、不发送邮件、不修改后端。没有部署或提交 Git commit。
